AUDITOR DE RECORRIDOS — CÓMO RECOMPILAR
═══════════════════════════════════════════════════════════════

CUÁNDO RECOMPILAR
─────────────────
Cada vez que modifiques GPS_Auditor_G.html (o cualquier
archivo dentro de public/) necesitás generar un nuevo .exe.

PASOS
─────

1. EDITÁ TU ARCHIVO
   Modificá public/GPS_Auditor_G.html con los cambios.

2. ABRÍ POWERSHELL EN LA CARPETA DEL PROYECTO
   Shift + Click derecho en auditor-recorridos/
   → "Abrir ventana de PowerShell aquí"

3. COMPILÁ
   npm run build

4. ESPERÁ 2-3 MINUTOS
   El .exe nuevo queda en:
   dist/Auditor de Recorridos 1.0.0.exe

5. DISTRIBUÍ EL .EXE NUEVO
   Copialo y compartilo. El anterior queda obsoleto.

═══════════════════════════════════════════════════════════════
LIMPIEZA (opcional)
═══════════════════════════════════════════════════════════════

Antes de recompilar podés borrar la carpeta dist/ para
arrancar limpio. npm run build la regenera sola.

NUNCA borres:
  ✗ node_modules/
  ✗ main.js
  ✗ package.json
  ✗ public/GPS_Auditor_G.html

Podés borrar libremente:
  ✓ dist/  (se regenera con npm run build)
